ATFT factory overview

The parallel line in atft/.assembly-lines. An optional plan check vets each task before the doer starts, and three reviewers then check the doer's work at the same time. The plan check, guard rails and logging are all controlled from factory/appsettings.json. The plan check's extractor, two reviewers and synthesiser are drawn as one node, and the start node is omitted.

appsettings.json · PlanCheck

Plan check

  • Extracts only the next task, so reviewers never see the whole plan.
  • GPT 6.1 Sol and Claude Opus 5.5 review it through OpenRouter, in parallel.
  • A rejected task goes back to the planner with the findings. Set Enabled to false to skip all of it.

appsettings.json · Guards

Guard rails

  • MaxTasks 40 and a frozen task list stop a plan that keeps growing.
  • Three tasks in a row with no file changes stop the run.
  • A machine gets 30 minutes before it is stopped.

appsettings.json · Logging

Run log

  • factory.log records every call, result and route.
  • Each response is kept in history/.
  • Set Console to true to watch it live.
