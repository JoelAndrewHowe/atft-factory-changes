# Vision

## Goal
Create a web application that takes a user through the process of creating an automated API test. It should break the process down so that it's clear, provide instruction for each step, and give the user a chance to step through the process for themselves. For the capstone, this means taking one example API test and creating a tutorial that would guide the user in how to write the test themselves.

## What the API test framework tutorial is
The API test framework tutorial is a web app that enables the user to step through a simulated API automation test, to see how each component is built. Its tutorial approach teaches the user as they move through the process, to give a solid introduction to writing these tests.

## Principles

- **C# test automation framework**: The application teaches API automation testing using a C#, ReqnRoll, Selenium framework. 
- **IDE style**: The application is designed to resemble an IDE, where the user has space to write code based on the instructions provided. 
- **Step by step tutorial**: The tutorial system will take the user through each step of building an API test, from writing the feature, to creating the step definitions, to setting up models to reflect the expected data received. 
- **Clarity**: Each step is easy to understand. The application provides an explanation for each step suitable for someone with coding experience, but is new to API test automation. 
- **Practical learning**: The system provides an example for the user to learn from, then asks them to replicate the same work on the tutorial's API test.
- **Responsive teaching**: If the user is stuck on a step, the API test framework tutorial system is able to show the solution. If the user submits work that is incorrect, the tutorial will highlight the error so the user knows to review their work.
